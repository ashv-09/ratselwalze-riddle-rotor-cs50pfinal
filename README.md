## Background:

The Enigma Machine was invented by a German engineer names Arthur Scherbius at the end of WWI and was sold commercially in the 1920s
for businesses and financial institutions to safeguard information. During WWII, the German military adopted and modified the machine in
order to pass secure communications and informations regarding troop-formations, attacks, supplies, etc. The process of the Enigma Machine
ensured that different rotors were used each time so that interceptors wouldn't know which rotor to decrypt from. Eventually, through
the course of the war, mathematicians from the Allies' side were able to break the cipher pattern and create counter-machines like bombes,
allowing the Allies to read intercepted German messages.


## Functionality:

- A user will be prompted to type a message
- The rotors (the behavior of which is determined by the code within functions), starting positions, and plugboard pairs will return
  an encrypted output similar to how a real Enigma machine would produce.
- If a user decides to run the ciphertext through the same settings then the new output should be the original message.
